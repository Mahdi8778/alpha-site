راهنمای نصب نسخه جدید ALPHA

این نسخه برای جایگزینی فایل‌های قبلی در GitHub Pages آماده شده است.

چه چیزهایی دارد؟
- رابط تیره و شیشه‌ای شبیه نمونه‌ای که فرستادی
- مدل انسان‌نمای سه‌بعدی VRM (از یک نمونه عمومی VRoid)
- حرکت طبیعی خیلی ملایم سر و پلک، در صورتی که مدل expression مربوطه داشته باشد
- باز و بسته شدن تقریبی دهان هنگام صدای ALPHA
- تشخیص صدای فارسی با میکروفون در مرورگرهای سازگار
- خواندن پاسخ‌ها با صدای فارسی سیستم/مرورگر

نکته مهم:
1) مدل سه‌بعدی از اینترنت و نشانی عمومی GitHub بارگذاری می‌شود؛ پس بار اول اینترنت لازم است.
2) ظاهر مدل آماده دقیقاً مو و چهره عکس مرجع تو نیست؛ این یک مدل پایه آزاد برای راه‌اندازی واقعی سه‌بعدی است. می‌توان بعداً مدل را با مدل اختصاصی سفیدمو و چشم‌آبی عوض کرد.
3) گفتگوی این نسخه هنوز هوش مصنوعی واقعی نیست؛ چند پاسخ آزمایشی دارد. برای پاسخ هوشمند واقعی باید یک سرویس AI و بک‌اند امن اضافه شود. کلید API را داخل فایل‌های GitHub Pages قرار نده.
4) هماهنگی لب با صدا تقریبی است، نه لب‌خوانی دقیق واج‌به‌واج. تشخیص دقیق نیازمند مدل صورت با viseme/blendshape مناسب است.
5) میکروفون روی سایت HTTPS (GitHub Pages) و با اجازه کاربر کار می‌کند. Chrome یا Edge پیشنهاد می‌شود.

جایگزینی در GitHub:
1. فایل ZIP را از حالت فشرده خارج کن.
2. وارد مخزن GitHub خودت (alpha-site) شو.
3. روی Add file > Upload files بزن.
4. فایل‌های index.html و style.css و script.js و README_FA.txt را از پوشه بیرون‌آمده انتخاب کن.
5. اگر پرسید فایل‌ها جایگزین شوند، تأیید کن.
6. پایین صفحه روی Commit changes بزن.
7. حدود 1 تا 3 دقیقه صبر کن و سایتت را Refresh کن.

اگر مدل بارگذاری نشد:
- مطمئن شو آدرس سایت با https شروع می‌شود.
- اینترنت را بررسی کن؛ مدل از مخزن عمومی دانلود می‌شود.
- با Chrome یا Edge امتحان کن.

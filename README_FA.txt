راهنمای فارسی ALPHA - نسخه مرورگری

۱) فایل ZIP را از حالت فشرده خارج کن (Extract All).
۲) برای آزمایش، روی index.html دوبار کلیک کن تا در مرورگر باز شود.
۳) برای انتشار رایگان و گرفتن لینک عمومی:
   الف) وارد https://github.com شو و یک حساب بساز یا وارد شو.
   ب) روی New repository بزن.
   ج) نام مخزن را alpha-site بگذار و حالت Public را انتخاب کن.
   د) Create repository را بزن.
   هـ) Add file > Upload files را انتخاب کن.
   و) فایل‌های index.html و style.css و script.js و README_FA.txt را از پوشه خارج‌شده بکش و در صفحه رها کن.
   ز) Commit changes را بزن.
   ح) به Settings > Pages برو.
   ط) در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کن.
   ی) Branch را روی main و پوشه را روی /(root) بگذار و Save را بزن.
۴) کمی صبر کن؛ لینک سایت در همان صفحه Pages نمایش داده می‌شود. آن لینک را برای دوستانت بفرست.

نکته‌ها:
- این نسخه بدون API و بدون سرور است؛ پاسخ‌ها آزمایشی و از پیش تعریف‌شده‌اند.
- برای نمایش فونت فارسی، هنگام باز بودن اینترنت فونت از Google Fonts بارگیری می‌شود.
- هرگز کلید API را داخل فایل‌های سایت قرار نده؛ اگر بعداً هوش مصنوعی واقعی اضافه شد، کلید باید فقط در سرور نگهداری شود.
